# SecureByte Technician Lab

A hands-on IT support, computer repair, networking, and cybersecurity lab built to develop and demonstrate practical technical skills using a repeatable service workflow.

> **Portfolio scope:** These are controlled lab exercises and sanitized simulations. No customer credentials, personal files, serial numbers, recovery keys, private IP details from real environments, or other sensitive information belong in this repository.

## Methodology

**Intake → Protect Data → Diagnose → Recommend → Authorize → Repair → Validate → Secure → Document → Handoff**

## 12-Week Program

| Week | Lab | Primary Skill |
|---|---|---|
| 01 | Repair Bench Setup | Tools, ESD, workflow |
| 02 | Windows Clean Install | OS deployment |
| 03 | Slow PC Diagnostics | Performance / hardware diagnosis |
| 04 | HDD-to-SSD Upgrade | Migration and validation |
| 05 | Boot Failure Recovery | Windows recovery |
| 06 | Malware Investigation | Endpoint investigation |
| 07 | Secure PC Baseline | Windows hardening |
| 08 | Backup & Restore | Recovery testing |
| 09 | Network Troubleshooting | DHCP, DNS, gateway, packet capture |
| 10 | Secure Home Network | Wi-Fi, guest/IoT segmentation |
| 11 | Customer Repair Simulation | Full service workflow |
| 12 | Capstone Repair | Unknown-fault end-to-end job |

## Documentation

The `/docs` folder contains SecureByte working forms and checklists used to make each lab resemble a professional service engagement.

## Evidence Standard

Each completed lab should include:
- Objective and scenario
- Environment and tools
- Initial symptoms
- Diagnostic methodology
- Evidence and findings
- Repair/remediation
- Validation results
- Security/privacy considerations
- Lessons learned
- Sanitized screenshots/photos where useful

## Disclaimer

This repository documents training and simulated service work. It does not represent a guarantee of security, data recovery, or repair outcomes.
