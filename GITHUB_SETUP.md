# GitHub Setup

1. Create a repository named `securebyte-technician-lab`.
2. Copy the contents of this folder into the repository.
3. Commit the initial structure before completing labs.
4. Work one lab at a time.
5. Replace template text with your own observations and evidence.
6. Put only sanitized screenshots/photos in each lab's `images/` folder.
7. Commit after each meaningful milestone.

Suggested commit messages:
- `docs: add SecureByte service workflow templates`
- `lab01: document repair bench setup`
- `lab02: complete Windows clean install`
- `lab03: document slow PC diagnosis`

## Portfolio rule
Write what you actually did. Do not claim a repair, tool, finding, or result that you did not personally perform and verify.
