# Post-Repair Security Check

- [ ] Supported OS / updates reviewed
- [ ] Defender or approved endpoint protection healthy
- [ ] Firewall enabled
- [ ] Secure Boot checked
- [ ] TPM checked when applicable
- [ ] Encryption status reviewed
- [ ] Accounts reviewed
- [ ] Backup status reviewed
- [ ] Browsers updated
- [ ] Suspicious extensions/proxy/DNS reviewed when indicated
- [ ] Customer actions documented
