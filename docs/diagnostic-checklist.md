# Diagnostic Checklist

## Protect Data
- [ ] Authorization confirmed
- [ ] Device condition documented
- [ ] Backup requirement evaluated

## Hardware
- [ ] Power/PSU/adapter
- [ ] Physical inspection
- [ ] Temperatures/fans
- [ ] Memory test if indicated
- [ ] Storage SMART/health

## Windows
- [ ] Boot behavior
- [ ] Disk space/resource use
- [ ] Device Manager
- [ ] Updates
- [ ] Relevant Event Viewer evidence

## Network
- [ ] IP/gateway/DNS
- [ ] Gateway/internet reachability
- [ ] Name resolution

## Security
- [ ] Defender/AV
- [ ] Firewall
- [ ] Suspicious startup items if indicated
- [ ] Secure Boot/TPM/encryption if in scope
